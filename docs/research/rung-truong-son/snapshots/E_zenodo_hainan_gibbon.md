Hainan gibbons (Nomascus hainanus) calls for passive acoustic monitoring

Dufourq, Emmanuel and Batist, Carly and Foquet, Ruben and Durbach, Ian.

"critically endangered Hainan gibbons (Nomascus hainanus)"

"This dataset contains approximately 10 hours of audio"

"The audio data was collected in the Bawangling National Nature Reserve, Malawi using 8 Song Meter SM3 recorders."

"The sampling rate was set to 9,600Hz and the recordings were collected between March to August 2016."

Audio.zip and Annotations.zip (Annotations.zip: 127.2 kB; the second listed file is 11.0 GB)

Notes: The page does not show a license, so none is copied. The page lists the location as Malawi, but Bawangling National Nature Reserve is in Hainan, China, so that wording may be an error. The file names for the 11.0 GB entry are not shown; I matched it to the audio file from the description.
