# TIP-011: Look-dev slice — render pipeline, môi trường, vật liệu thật (G0.5)

## HEADER
- TIP-ID: TIP-011 · Project: HT-MB · Module: `src/engine/render/{post,environment,assets,materials,arena,lighting,rain}.ts`, `content/assets/`, `scripts/fetch-assets.mjs`
- Depends on: TIP-010, ADR-005 · Priority: P0 · Estimated effort: 4–6 h Thợ
- Không phụ thuộc Chủ nhà (chỉ CC0). Nhân vật (Mixamo) là TIP-012, súng/FX là TIP-013.

## CONTEXT
- Chủ nhà đánh giá G0 "game thập niên 90". ADR-005 chẩn đoán 5 nguyên nhân; TIP này xử lý 1–3 + 5 (texture, IBL, post stack, mưa) và một phần 4 (hình khối cảng thay hộp).
- PRD §1 lời hứa thị giác: mặt đường ướt, ánh đèn xuyên mưa, khói bụi, tia lửa, PBR có chiều sâu. §4: Post FX node stack, bloom/grade/vignette nhẹ, SSAO theo quality flag; Lighting 1 key shadow + ≤2 local shadow; Texture mipmap bắt buộc.
- Ràng buộc: TSL only; ArenaData (collider/waypoint/spawn/zone) là nguồn sự thật cho physics/nav/AI — **không đổi vị trí/kích thước collider**; chỉ đổi hình đại diện. Không Math.random. Budget không đổi.

## TASK
1. **Asset pipeline CC0**: `scripts/fetch-assets.mjs` tải từ Poly Haven API (texture 1K/2K JPG: diffuse, nor_gl, arm; HDRI 1K .hdr đêm; vài model glTF props 1K) vào `public/assets/`, ghi `content/assets/manifest.json` (schema `content/schemas/asset-manifest.schema.json`: id, type, source, url, license, files[], bytes, sha256). Unit test: manifest hợp lệ schema, mọi file tồn tại, tổng bytes < 60 MB, license ∈ {CC0-1.0, Mixamo}.
2. **Environment/IBL** `environment.ts`: HDRI đêm → `PMREMGenerator` → `scene.environment` (intensity thấp ~0.35) + `scene.background` gradient tối (không dùng HDRI làm nền để giữ bầu trời mưa). Fog exp2 màu lạnh hơn.
3. **Post stack** `post.ts`: `RenderPipeline` + `pass(scene, camera)` MRT {output, normal, metalness, roughness, velocity}; tier: low FXAA+bloom · medium +GTAO(0.5×) · high +SSR(0.5×, non-metal reflect cho sàn ướt)+TRAA; film grain 0.08 + vignette 0.35 + tone mapping AgX qua `outputColorTransform`. Telemetry: thêm `post_ms` nếu đo được; `renderer.info` vẫn đọc được. WebGL2 fallback phải chạy tier low (CI).
4. **Vật liệu thật** `materials.ts`: sàn = asphalt/concrete PBR 2K (map/normal/arm) + **puddle mask** noise (roughness→0.05, normal→phẳng, darken) + **gợn mưa** procedural TSL trên vũng (normal xoay theo time); tường = bê tông; container = tôn sóng + sơn tróc + rỉ (normal + roughness); thùng phuy = kim loại rỉ; crate = gỗ/ván ép. UV scale theo mét.
5. **Hình khối cảng** `arena.ts`: cover block → container 20 ft (khung, cửa, thanh khoá, gân sóng bằng normal map; 3 màu) — collider box giữ nguyên 6×2.6×2.4; props BatchedMesh: thay 3 geometry hộp bằng crate/pallet/jersey barrier có vát cạnh (cùng collider); thùng phuy: rim + gân. Thêm **cột đèn natri** 6 cái (mesh + SpotLight 2 shadow-less + chóp sáng emissive + nón volumetric giả additive) và **bảng hiệu emissive** "CẢNG VẠN HẢI" (text từ i18n/content, không literal TS).
6. **Mưa**: giữ GPU-only; opacity theo khoảng cách tới đèn (sáng khi cắt nón đèn); **splash ring** instanced trên sàn (pool 512, life 0.3 s, seeded) — hoặc gợn trên puddle nếu splash quá tốn.
7. **Quality preset** mở rộng: `post: 'off'|'low'|'medium'|'high'`, `textures: 1|2 (K)`; `?post=` override; CI dùng `quality=low&post=low`.

## ACCEPTANCE CRITERIA
- Given Mac WebGPU high, Then screenshot 1920 có: phản chiếu đèn trên sàn ướt (SSR), bloom trên đèn/visor/tracer, AO ở chân container, grain nhẹ; **Chủ nhà chấm** "không còn 90s".
- Given `npm run bench:quick` trên Mac, Then verdict PASS (p95 < 18.5 ms); ghi A/B trước/sau: gpu_ms, draw, tris. Kỳ vọng GPU 6–9 ms ở high.
- Given `?quality=low&post=low&backend=webgl`, Then CI E2E 6/6 pass (SwiftShader) và không lỗi console.
- Given manifest, Then unit test schema + tồn tại file + license + tổng bytes pass; `initial_payload_mb` đo được (dist + assets tải lúc boot) ghi vào report.
- Given collider, Then `arena.colliders` hash trước/sau **giống hệt** (unit test snapshot) — physics/nav/AI không đổi.
- Given governance.test, Then 0 vi phạm; không literal VI trong TS.

## CONSTRAINTS
- Không ShaderMaterial; không Math.random; không đổi three version; không đổi budget; không asset ngoài CC0 (Mixamo là TIP-012).
- Texture ≤ 2K, tổng assets tải lúc boot ≤ 60 MB ở slice này (KTX2 nợ — ADR-005).
- Không hạ rain/shadow toàn cục để qua budget; nếu WARN → tối ưu pass cụ thể (resolutionScale, samples).
