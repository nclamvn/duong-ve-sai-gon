## SPECIFICATIONS
- `content/missions/g0-arena.mission.json`: `MissionDefinition {id:'g0-arena', version:'0.1.0', seedPolicy:'fixed', seed: 7, startNode:'n_intro', checkpoints:['cp0'], localization:'vi', nodes:[...]}`. Nodes: `n_intro` (action `radio D01`, `objective obj_reach_relay`) → `n_zone` (enterConditions `zone_enter relay_zone`; actions `radio D03`, `spawn bot_group_a`) → `n_clear` (exitConditions `group_dead bot_group_a`; actions `radio D05`, `objective_complete`, `checkpoint cp0`) → `n_done` (action `mission_complete`). Mỗi node có `timeoutMs` + `fallbackNext`.
- `types.ts`: kiểu MissionDefinition/MissionNode/Action/Condition; **allow-list action**: `radio, objective, objective_complete, spawn, checkpoint, mission_complete, set_flag`; condition: `zone_enter, group_dead, flag, timeout`. Action ngoài allow-list → loader reject.
- `loader.ts`: `loadMission(json)` validate ajv (mission.schema + dialogue.schema); lỗi → `MissionValidationError` liệt kê path.
- `runtime.ts`: `MissionRuntime(def, deps {events, spawner, zones, subtitles, i18n})`: `step(tick)`; node enter → chạy actions với event id `${missionId}:${nodeId}:${actionIdx}` (idempotent qua EventBus); `state {currentNode, flags, objectives, groupsAlive, timers}`; `snapshot()` → `CheckpointSnapshot {missionFlags, actors, player, inventory, doors:[], timers, node}`; `restore(snapshot)` phải **xóa** runtime state cũ trước (despawn, clear timers, reset event ring) rồi mới apply.
- `checkpoint.ts`: `CheckpointStore` lưu snapshot vào memory + IndexedDB store `ht-checkpoint`; `stateHash(snapshot)` (JSON canonical + FNV-1a) để test restart invariant.
- `subtitles.ts` (ui): hàng phụ đề dưới màn hình `[VY] …` từ `vi.json` key `dlg.D01`, speaker label, kích thước theo Settings; ẩn sau `durationMs` hoặc khi cue ưu tiên cao hơn tới (priority, interruptPolicy từ dialogue.schema).
- `hud.ts`: objective text, health, ammo, interact prompt (G0 chỉ hiển thị "F — Cắt relay" khi trong `relay_zone`; nhấn F → `set_flag relay_cut`).
- `debugApi.ts`: `window.__ht` mở rộng: `teleport(x,y,z)`, `setSeed(n)`, `mission.state()`, `mission.trigger(nodeId)`, `checkpoint.save()/load()`, `stateHash()`, `reset()`, `events.recent(n)`, `kill('bot_group_a')`. Gate `if (import.meta.env.PROD && !location.search.includes('debug=1')) return`.
- `game.reset(seed)`: đưa toàn bộ (player, bot, dummies, weapon, mission, pools, event ring) về trạng thái đầu — dùng cho bench và test.

## ACCEPTANCE CRITERIA
- Given mission JSON hợp lệ, When loadMission, Then OK; Given action `explode_map`, Then reject với path `nodes[1].actions[0].type`.
- Given runtime, When player vào `relay_zone`, Then radio D03 phát đúng 1 lần dù `zone_enter` bắn 5 lần liên tiếp (duplicates = 4), bot_group_a spawn 1 lần.
- Given group chết, Then `n_clear` chạy, checkpoint `cp0` lưu, objective complete; sau đó `n_done` → event `MISSION_COMPLETE` đúng 1 lần.
- Given snapshot S tại cp0, When chơi thêm 30 s rồi `restore(S)`, Then `stateHash()` === hash lúc lưu; số actor sống đúng; không event duplicate sau restore (ring đã reset). Lặp 20 lần → 20/20.
- Given node `n_zone` có `timeoutMs 60000`, When không vào zone 60 s, Then fallbackNext chạy và log `NODE_TIMEOUT`.
- Given `PROD` build không `?debug=1`, Then `window.__ht` undefined.
- Given mọi chuỗi UI, Then không có literal tiếng Việt trong `src/ui/*.ts` ngoài `i18n.ts` (grep test).
