## TASK
1. **Pipeline** `scripts/convert-weapon.mjs --src assets-src/sketchfab/<slug> --id <id> --length <m> [--simplify r] [--texture px]`:
   glTF Sketchfab → gltf-transform (dedup/prune/weld/quantize/meshopt; texture WebP ≤ 2K, normal lossless) → chuẩn hoá hướng
   (nòng −z, lên +y, gốc = tâm tay cầm) → in danh sách node + bbox để điền JSON anchor → `public/assets/weapons/<id>.glb` + manifest (CC-BY, attribution).
2. **`content/weapons/<id>.json`** (schema `content/schemas/weapon-model.schema.json`): `model`, `scale`, `anchors {muzzle, eject, gripR, gripL, sight, magazine}`,
   `parts {magazine, bolt, chargingHandle?}` (tên node), `pose {hip, ads, sprint, reloadDip}`, `handOffset` (bone RightHand cho địch).
3. **`weaponModel.ts`** (engine): `loadWeaponModel(url, cfg)` → `{ scene, anchors, parts, triangles }`; `instantiate()` clone chia sẻ geometry/material;
   material glTF giữ nguyên (PBR), thêm `envMapIntensity` theo scene.
4. **Địch:** `attachRifle(bone, weapon?)` dùng glTF nếu có (gốc = gripR, offset `handOffset`), fallback procedural. `ActorVisual.muzzleWorld(out)` → vị trí đầu nòng thế giới.
5. **Lửa nòng địch:** `fx.botMuzzle = (botId, out) => boolean` (Game gán); BOT_FIRED → flash + spark + khói + tracer **từ đầu nòng**; 1 PointLight `botLight`
   (luôn trong scene, intensity 0 khi nghỉ) cho phát bắn địch gần nhất; hướng tracer = dir sự kiện.
6. **Viewmodel người chơi:** thay procedural bằng glTF AK-74M: pose hip/ADS/sprint từ JSON; **ADS căn đường ngắm** (anchor `sight` về tâm màn hình);
   kick/sway/bob giữ; **reload**: băng đạn (node) tụt xuống-ra rồi lắp lại + dip; **bolt** giật lùi 0.03 s mỗi phát; casing từ anchor `eject`;
   bao tay vải giữ (đặt theo `gripR`/`gripL`). Fallback: không có GLB → viewmodel procedural TIP-013 (CI `?assets=0`).
7. **Credits:** README §Credits + `CREDITS.md` sinh từ manifest (`npm run assets:credits`), chuỗi `ui.credits` trên màn capability; `assets.test` bắt buộc `attribution` cho CC-BY.
8. Evidence: ảnh viewmodel hip/ADS/reload/bắn, địch bắn (flash tại nòng), lineup; `npm run ci`; bench:quick Mac (Chủ nhà).

## ACCEPTANCE CRITERIA
- Given GLB vũ khí có trong manifest, Then người chơi cầm AK-74M PBR; ADS nhìn qua thước ngắm, tâm màn hình trùng đường ngắm (±0.5°); reload thấy băng đạn tháo/lắp; bắn thấy bolt giật.
- Given địch bắn, Then flash/spark/khói/tracer xuất phát từ đầu nòng súng địch (sai số ≤ 5 cm so với anchor), có ánh sáng ngắn; không lỗi khi địch chết giữa lúc bắn.
- Given `?assets=0` hoặc thiếu GLB, Then viewmodel/prop procedural, không lỗi console; E2E cũ pass.
- Given manifest, Then mọi asset CC-BY có `attribution`, `url`, `authors`; CREDITS.md khớp manifest; tổng asset ≤ 60 MB.
- Given bench:quick Mac, Then PASS (Chủ nhà); tri viewmodel ≤ 20k, tri súng địch ≤ 20k/instance.
