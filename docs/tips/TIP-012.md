- TIP-ID: TIP-012 · Project: HT-MB · Module: `scripts/convert-mixamo.mjs`, `src/engine/render/characters.ts`, `src/game/actors/{dummy,botActor,soldierRig}.ts`

## CONTEXT
- Lính procedural 12 bone (TIP-010) đủ để đo, không đủ để "ấn tượng". Cần mesh người thật + mocap.
- Mixamo: 1 character FBX (có skin) + N animation FBX (without skin, cùng skeleton) → glTF; animation clip gộp vào 1 GLB; retarget không cần vì cùng rig.
- Hitscan hiện dùng `DUMMY_HIT_ZONES` (capsule/sphere cố định). Sau TIP này hit zone bám bone (head/spine/hips) nhưng giữ cùng kích thước để test cũ pass.

## INPUT (Chủ nhà tải, Adobe account — miễn phí)
Character (chọn 1, ưu tiên theo thứ tự): **Swat Guy** (lính SWAT có mũ, giáp), Vanguard By T. Choonyung, hoặc nhân vật có helmet/vest khác.
Export: Format FBX Binary, Skin **With Skin**, T-pose, Frames/s 30, Keyframe Reduction none.
Animations (tìm đúng tên; export **Without Skin**, 30 fps, "In Place" tick khi có):
1. `Rifle Idle` · 2. `Rifle Walk` (in place) · 3. `Rifle Run` (in place) · 4. `Rifle Aiming Idle` · 5. `Firing Rifle` (hoặc `Rifle Aiming Idle Firing`)

Đặt tên file đúng nhãn, ví dụ `swat.fbx`, `rifle_idle.fbx`, `rifle_walk.fbx`, … vào `assets-src/mixamo/`. Thợ sẽ stage và convert.

## TASK
1. `scripts/convert-mixamo.mjs`: FBX → glTF (FBXLoader trong Node qua three + headless canvas không cần; dùng `fbx2gltf` npm hoặc Blender nếu có) → gộp clip → glTF-Transform: prune, dedup, weld, quantize, meshopt, texture resize 1K/2K → `public/assets/characters/soldier.glb`; ghi manifest (license Mixamo).
2. `characters.ts`: loader (GLTFLoader + MeshoptDecoder), **1 SkinnedMesh/actor** (clone skeleton bằng `SkeletonUtils.clone`), material PBR từ glTF + visor/patch emissive theo phe; shadow cast on.
3. `soldierRig.ts`: AnimationMixer state machine — idle/walk/run (blend theo speed), aim (additive upper body nếu được, không thì crossfade), fire (một lần, 0.12 s), reload, hit, death (giữ frame cuối). Tất cả trong render tier, đọc `motion` như Dummy hiện nay → `Dummy` thành interface `ActorVisual` với 2 implementation (procedural fallback khi thiếu GLB → CI/sandbox vẫn chạy).
4. Hit zone bám bone: head sphere tại bone Head, body capsule Hips→Neck; kích thước giữ (0.16 / 0.28).
5. Bench: 9 skinned mesh Mixamo (~10–20k tri/nhân vật) + mixer 9 → đo `cpu_render`, `skinned_actors`.

## ACCEPTANCE CRITERIA
- Given GLB có sẵn, Then 8 dummy + bot dùng Mixamo mesh; thiếu GLB → fallback procedural, không lỗi (E2E sandbox không cần GLB).
- Given bot đi/chạy/ngắm/bắn/chết, Then animation đúng state; chuyển state crossfade ≤ 0.2 s; không T-pose lộ.
- Given 60 phát trúng, Then hit zone theo bone trúng đúng như capsule cũ (unit test so sánh tỉ lệ head/body).
- Given bench:quick Mac, Then PASS; `skinned_actors` ≤ 10.
- Given manifest, Then license Mixamo ghi cho từng file nguồn.

## CONSTRAINTS
