## TASK
Overlay telemetry, ring buffer metrics với p95, replay runner, xuất `performance-report.json`, và lệnh `npm run bench` ghi evidence qua Vite middleware.

## SPECIFICATIONS
- `telemetry.ts`: `Telemetry` ring buffer 1024 frame `{frameMs, cpuSimMs, cpuRenderMs, gpuMs?, calls, tris, actorsFull, actorsTotal, heapMB, scale}`; `summary()` → `{fps_avg, fps_1pct_low, frame_p95, frame_p99, cpu_sim_p95, calls_avg, tris_avg, heap_start, heap_end, heap_delta, scale_avg, frames, duration_s}`; `fps_1pct_low` = trung bình 1% frame chậm nhất quy ra FPS. GPU time: nếu `renderer.backend` có timestamp query (`renderer.info.render.timestamp`) thì đọc, else `null` + `gpu_method: "unavailable"`.
- `overlay.ts` (ui): DOM `<pre>` góc trái, cập nhật 4 Hz (không mỗi frame), màu: xanh ≤ target, vàng giữa, đỏ ≥ red. Toggle F3. Không dùng trong `PROD` trừ `?overlay=1`.
- `replay.ts` (engine/input): `InputTrack` = mảng `{tick, keys, dx, dy, fire}`; `ReplayPlayer(track)` cung cấp snapshot theo tick; `makeArenaTrack(seed, seconds)` sinh track deterministic (đi vòng arena, quay nhìn, bắn từng nhịp) từ prng.
- `bench.ts` (qa): `runBench({runs=3, seconds=90, seed})`: mỗi run: reset scene (gọi `game.reset(seed)`), warm-up 2 s, ghi telemetry `seconds` s, thu summary; lấy **median** theo `frame_p95`; report theo schema `performance-replay.schema.json`: `{seed, inputTrack: 'arena-v1', buildHash, device:{ua, dpr, hwConcurrency, adapter}, browser, backend, runs:[...], median, budgetCheck:{metric:{value,target,red,status}}, verdict:'PASS'|'WARN'|'FAIL'}`. Kích hoạt bằng `?bench=1&runs=3&seconds=90&autostart=1`; xong → `POST /__bench` JSON; nếu 404 (preview tĩnh) → tải file xuống.
- `scripts/bench-plugin.ts`: Vite plugin `configureServer`/`configurePreviewServer` middleware `POST /__bench` → ghi `evidence/G0/performance-report-<ISO>.json` + `device-profile.json`; trả `{saved: path}`.
- `npm run bench` = `vite --mode bench --open "/?bench=1&autostart=1&runs=3&seconds=90"`. `npm run bench:quick` = runs=1, seconds=10.
- `debugApi.ts` (qa) — khởi tạo phần metrics: `window.__ht = { metrics(), summary(), backend, buildHash, version }`; phần còn lại mở rộng TIP-008.

## ACCEPTANCE CRITERIA
- Given Telemetry với 1000 frame giả (990 × 16 ms, 10 × 40 ms), Then `frame_p95 ≈ 16`, `fps_1pct_low ≈ 25`, `frames === 1000`.
- Given `makeArenaTrack(7, 90)` gọi 2 lần, Then hai track bằng nhau từng phần tử (deep equal).
- Given headless WebGL2, When `?backend=webgl&bench=1&runs=1&seconds=3&autostart=1`, Then trong ≤ 20 s có `POST /__bench` và file `evidence/G0/performance-report-*.json` hợp lệ theo schema, `verdict` ∈ {PASS,WARN,FAIL}.
- Given overlay, When F3, Then ẩn/hiện; overlay không cập nhật quá 5 lần/giây (counter).
- Given budget FPS target 60 / red 40, When median fps_avg = 50, Then `budgetCheck.fps.status === 'WARN'`.
